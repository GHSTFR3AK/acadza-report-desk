Report Desk Acadza question fixes

Audit log

Every decision made on this device, newest first: who, when, what the system proposed and what was finally applied. It is stored in this browser, so download it to keep a copy.

    How to use the Report Desk

    1. Pick a question on the left. Each row is one question, however many students reported it.
    2. Read the case from top to bottom: what the system found, the exact change, and the question before and after.
    3. Decide with the buttons at the bottom. Each button says what will happen. Every decision is logged and can be undone.

    What the groups mean

    • Needs your decision: the system is not allowed to make this change alone. Start here.
    • Fixed automatically: already live after passing every safety check. Spot-check it; undo if you disagree.
    • Found by the system: defects nobody reported. Nothing has been changed.
    • No problem found: the question is correct. Check the reply the student will get.

    Reading a change

    Red, struck through is removed. Green, underlined is added.

    Why this order

    The queue answers one question: is a student losing marks on this right now? A wrong key or an unanswerable question comes before a missing value, then a wrong solution, then spelling. More reports push a question up; ties go to the oldest report.
